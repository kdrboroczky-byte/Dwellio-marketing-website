DWELLIO WEBSITE 2 – FELTÖLTÉS

1. A GitHub repository főoldalán válaszd: Add file → Upload files.
2. Jelöld ki a ZIP-ben található összes fájlt, a txt útmutató kivételével.
3. Hagyd kiválasztva: Commit directly to the main branch.
4. Nyomd meg: Commit changes.
5. Várj 1–3 percet, majd frissítsd a dwelliomarketing.com oldalt.

A képeket nem kell újra feltölteni. A weboldal a GitHub főmappájában már meglévő logo.png, ab-..., mg-... és sh-... fájlokat használja.
