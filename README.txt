DWELLIO WEBSITE 2.0

UPLOAD INSTRUCTIONS
1. Delete or replace the old website files in the GitHub repository only after downloading a backup.
2. Upload every file and the complete assets folder from this package.
3. Keep the folder name exactly: assets
4. Do not upload only index.html; all files must be uploaded together.
5. Wait a few minutes for GitHub Pages to rebuild, then refresh Safari.

This package contains only local image paths, so images do not depend on external links.
